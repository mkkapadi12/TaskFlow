# TaskFlow

> **Organize your work. Empower your life.**

TaskFlow is a modern, collaborative task and project management workspace designed to help teams align, track progress, and secure documentation efficiently. By bridging task management, documents, and real-time communications, TaskFlow ensures projects move forward smoothly with role-based access controls.

---

## 🚀 Key Benefits

- **Clear Accountability**: Keep ownership precise with task assignees, project managers, and verify-to-complete workflows.
- **Centralized Documentation**: Keep project and task documents alongside discussions, eliminating scattered files.
- **Real-Time Alignment**: Stay updated instantly with in-app notifications and live email alerts.
- **Data Protection**: Archive inactive projects to preserve history in read-only mode while preventing accidental edits.
- **Intuitive Visuals**: Track statuses at a glance through Kanban boards, calendar layouts, and analytics graphs.

---

## ✨ Features

### 📋 Project & Member Management
- **Role-Based Collaboration**: Add members to projects with granular roles (`OWNER`, `ADMIN`, `MEMBER`).
- **Project Archiving (Soft-Deletes)**: Archive completed or inactive projects. Archived projects are locked as strictly read-only, protecting comments, tasks, and files.

### ⏱️ Task Workspace & Kanban
- **Task Lifecycle**: Move tasks through `To Do` ↔ `In Progress` ↔ `In Review`.
- **Verification Gate**: Only project owners can verify tasks to `Done` or send them back to `In Progress` for revisions.
- **Kanban Board**: Drag-and-drop tasks across status columns within project scopes.
- **Checklists & Reminders**: Visual deadlines, custom priorities, and automatic email notifications for tasks due within 24 hours.

### 📎 Task Attachments & Previews
- **Assignee-Only Uploads**: Only the assigned member can upload raw attachments (up to 20MB) to their task.
- **Inline Preview**: Open and view PDFs, Markdown, text, and images directly in the browser using the premium preview viewer.
- **Uploader/Manager Deletion**: Only the file uploader or project managers can delete attachments.

### 📁 Centralized Requirements & Documents
- **Search & Filter**: Search files instantly and filter by file extension type.
- **Bulk Action & ZIP Download**: Multi-select documents to package and download them as a single ZIP archive.
- **Workspace Dashboard**: Review documents globally across all projects you belong to.

### 💬 Discussions & Activity Audits
- **Comment Threads**: Exchange notes and feedback directly inside task side-panels.
- **System Activity Log**: Auto-generated audit trails showing assignee changes, status updates, and deadline modifications.

### 📊 Dashboard & Calendar
- **Interactive Calendar**: View deadlines on a monthly calendar layout.
- **Visual Analytics**: Analyze status distributions, workload, and task completion velocity through dynamic charts.

---

## 🛠️ How It Works

1. **Create and Invite**: An Admin creates a project and invites team members, assigning them roles (`ADMIN` or `MEMBER`).
2. **Define and Assign Tasks**: Project managers define tasks, set priorities, establish deadlines, and assign them to members.
3. **Attach Reference Materials**: Assignees upload relevant documents (PDFs, spreadsheets, images) to their tasks for context.
4. **Update Status**: Assignees move tasks from `To Do` to `In Progress`, and finally to `In Review` when ready.
5. **Verify and Complete**: The project Owner reviews the completed work. They approve the task to mark it `Done` or request changes, which sends it back to `In Progress`.
6. **Archive for History**: Once the project milestones are hit, the Owner archives the project, turning the entire workspace into a read-only historical archive.
